# HR Analytics Dashboard | Power BI

##  Project Overview

This project is an interactive **HR Analytics Dashboard built using Microsoft Power BI** to analyze employee data and provide insights into workforce trends, employee demographics, attrition, and key HR metrics.

The dashboard transforms raw employee data into interactive visualizations and KPIs that can help HR teams understand workforce patterns and support data-driven decision-making.

##  Objectives

- Analyze overall workforce characteristics
- Track key HR and employee metrics
- Understand employee demographics
- Analyze employee attrition and workforce trends
- Identify patterns across departments and job roles
- Create interactive dashboards for HR analysis
- Present data-driven insights through effective visualizations

##  Dataset

The dataset contains employee-level information such as:

- Employee details
- Age and gender
- Department
- Job role
- Job level
- Education
- Salary-related information
- Years at company
- Job satisfaction
- Work-related factors
- Attrition

##  Data Preparation

The following data preparation steps were performed in Power BI:

- Imported the HR dataset into Power BI
- Reviewed data types and column values
- Checked for missing and inconsistent data
- Cleaned and transformed the dataset
- Prepared fields for analysis and visualization
- Created calculated measures for key HR metrics

##  Dashboard Analysis

The dashboard provides insights into:

### Workforce Overview

- Total Employees
- Employee Attrition
- Average Age
- Average Salary
- Average Years at Company

### Employee Demographics

- Employee distribution by gender
- Age distribution
- Education levels
- Job levels

### Department & Job Role Analysis

- Employee distribution by department
- Employee distribution by job role
- Attrition across departments
- Attrition across job roles

### HR Trends

- Attrition patterns
- Salary-related trends
- Job satisfaction
- Employee experience and tenure

##  Key Visualizations

The dashboard includes interactive:

- KPI Cards
- Bar Charts
- Column Charts
- Donut Charts
- Slicers
- Interactive filters
- Comparative visualizations

These visualizations allow users to explore employee data based on different departments, roles, demographics, and other HR attributes.

##  Key Insights

The analysis helps identify:

- Overall workforce and attrition patterns
- Departments and roles with higher employee turnover
- Employee demographic distribution
- Relationship between employee experience and workforce trends
- Differences in employee characteristics across departments and job roles
- HR metrics that can support workforce planning
